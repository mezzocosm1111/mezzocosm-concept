# Bundled third-party assets

- Three.js 0.170.0, https://github.com/mrdoob/three.js/tree/r170 — MIT, see LICENSE-three.txt.
- Archivo Black, https://github.com/google/fonts/tree/main/ofl/archivoblack — SIL Open Font License, see LICENSE-archivo.txt.
- Instrument Sans variable font, https://github.com/google/fonts/tree/main/ofl/instrumentsans — SIL Open Font License, see LICENSE-instrument.txt.
- IBM Plex Mono Regular, https://github.com/google/fonts/tree/main/ofl/ibmplexmono — SIL Open Font License, see LICENSE-plex.txt.

Fonts and Three.js are self-hosted, downloaded directly from the projects' source/CDN distributions. No runtime CDN or third-party tracking requests are used.
